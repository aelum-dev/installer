# Frontend agent context (Svelte 5)

Specialized Svelte guidance ships as repo skills — load them when writing, editing or
analyzing `.svelte` components or `.svelte.ts` modules:

- **`svelte-code-writer`** — Svelte 5 documentation lookup + code analysis tooling.
  Use it to answer API questions and to check written code.
- **`svelte-core-bestpractices`** — guidance on writing fast, robust, modern Svelte
  code: reactivity (runes), events, styling, integration patterns. Load it in any
  task that touches Svelte files.

Project-specific frontend rules (stores, i18n, generated constants, e2e harness) are in
the root `AGENTS.md` and `frontend/e2e/README.md`.
